# Altair Magauya

Student in Kazakhstan interested in applied mathematics, optimisation, and Python. I build projects that connect mathematical models with practical problems.

## Selected projects

### [FretOPT](https://github.com/rattleh83d/FretOPT)
Guitar fingering optimisation using dynamic programming and a physical fretboard cost model. An exploration of how playing experience can inform an explicit, testable mathematical model.

### [Zhastar Media Toolkit](https://github.com/rattleh83d/sorting-for-zhastar)
Tools developed for a media-organisation workflow at Zhastar Üni: photo grouping, human review, optional OCR, and archive verification. The public release includes synthetic examples and offline regression tests.

## How I approach projects

- Start from a problem I have encountered through music or organisational work.
- Make assumptions and limitations explicit.
- Test the implementation and use feedback to improve the result.

Current interests: mathematical modelling, algorithms, actuarial science, and data science.
